# Huijiao Yang — Research website

English research homepage about biological inference, protein function, and machine learning.

Website: https://etheng-jiao.github.io/

## Editing

- `index.html` contains the complete page, including styles and the original SVG illustration.
- Edit project descriptions and links directly in `index.html`.
- `.nojekyll` serves the site as static HTML without Jekyll processing.
- GitHub Pages publishes the root of the `main` branch.

The page distinguishes completed work from ongoing research directions. Research wording remains a draft for the owner's review. No unpublished datasets, credentials, or private documents are included.
